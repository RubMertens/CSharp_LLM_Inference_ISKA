Dot Product — in Code

Straight out of the runner we're building. No library, no magic.

  1. Both vectors must have the same length — a dot product needs pairs.
  2. Multiply element by element, add it all up. One loop.
  3. Two vectors in, one number out. That number is alignment.
public static float operator *(Vector a, Vector b)
{
    if (a.Length != b.Length)
        throw new InvalidOperationException("Incompatible vector dimensions for dot product.");

    float sum = 0;
    for (var i = 0; i < a.Length; i++)
    {
        sum += a.Data[i] * b.Data[i];
    }
    return sum;
}

C# operator overloading: queries[i] * keys[j] is a dot product.
