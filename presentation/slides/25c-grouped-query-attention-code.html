Grouped Query Attention — in Code

32 query heads, 4 key/value heads. Every 8 queries share one K/V head.

  1. groupSize = query heads ÷ KV heads. Here: 8.
  2. Integer division maps a query head to its shared KV head.
  3. Offsets slice one head out of the big vector — no copies, just ranges.
  4. From there it's the same attention as before: score, softmax, weighted sum.

Fewer K/V heads = smaller cache = the reason long contexts are affordable.
