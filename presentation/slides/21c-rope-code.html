RoPE — in Code

Position isn't added to the vector. The vector gets rotated.

  1. Walk the vector two dimensions at a time — each pair is a 2D plane.
  2. Low dimensions rotate fast, high dimensions rotate slow. theta sets the speed.
  3. Angle = position × theta. Token 5 turns five times as far as token 1.
  4. Rotate the pair. Distance between two tokens now lives in the angle between them.
