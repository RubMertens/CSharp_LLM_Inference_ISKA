KV Cache — in Code

Prefill runs the whole prompt once. Every token after that is one vector through the stack.

  1. Position comes from the cache — its length is the token count so far.
  2. Project a single vector, not a matrix. No sequence loop anywhere.
  3. RoPE at this position, then append K and V to the cache. Write once, reuse forever.
  4. Attend the one query against everything cached. Per-token cost stops growing quadratically.
