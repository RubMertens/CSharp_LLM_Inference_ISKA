layout 2 — two column

Tokens in, tokens out

  • Byte-pair encoding splits text into subwords.
  • Each subword indexes a row of the embedding matrix.
  • That row is the only thing the model ever sees.
  • The final layer scores every token in the vocabulary.
  • Sampling picks one. Append, repeat.
  • No state survives between calls but the KV cache.
